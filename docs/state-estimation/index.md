## Proprioceptive Invariant State Estimation for Humanoid Robots on Non-Inertial Ground

  - State Estimation

### Summary

This paper presents an invariant extended Kalman filtering (InEKF) approach for real-time state estimation of humanoid robots operating on non-inertial ground using only onboard proprioceptive sensing.
